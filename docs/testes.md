# Testes

## Lint
Executar `npm run lint` e corrigir todos os erros.

## Build
Executar `npm run build` e confirmar compilação TypeScript e geração das rotas.

## Viewports
Testar 360 px, 390 px, 768 px, 1024 px e 1440 px, verificando ausência de rolagem horizontal.

## Interações
- Menu móvel abre e fecha.
- Busca filtra conteúdo local.
- Painel do candidato calcula projeção demonstrativa e salva em estado local.
- Timeline alterna etapa selecionada.

## Acessibilidade
Verificar landmarks, hierarquia de headings, labels de campos, foco visível, `aria-label` e contraste.

## Casos principais
- Acessar `/`.
- Acessar todas as páginas internas.
- Preencher painel do candidato.
- Navegar pelo teclado no menu e formulários.
- Conferir badges de classificação dos dados.
